# Horaris Igualada ↔ Barcelona (Monbus i FGC)

Web estàtica en català, sense dependències ni servidor. Obre `index.html` al navegador.

## Publicar a GitHub Pages

1. Crea un repositori i puja els tres fitxers d’aquesta carpeta a la branca principal.
2. A **Settings → Pages**, selecciona **Deploy from a branch** i la carpeta **/ (root)**.
3. Desa els canvis. La web apareixerà a l’adreça que indiqui GitHub Pages.

L’HTML conté les taules de totes dues fonts i es pot consultar sense Internet.
Els PDFs originals van inclosos en aquest paquet. Els enllaços online són:

- Bus: https://igualadanews.cat/wp-content/uploads/2025/08/Horaris-Monbus-2026.pdf
- Tren: https://www.fgc.cat/wp-content/uploads/2020/10/R6_Igualada_LA_octubre_20.pdf

**Notes:** calendari 2026; la data seleccionada significa sortida o arribada segons el mode;
el control de festius és manual (No per defecte, amb avís si és un festiu 2026 reconegut).
Els serveis nocturns d’FGC amb bus substitutori a Igualada no es mostren.
En direcció Igualada, Monbus indica Pg. Verdaguer (antic Hospital) al PDF.
Horaris sense seguiment en temps real.
